# Video-Game-Stock-Analysis
##Project Description
This project analyses the historical stock market data of top 10 video game companies using python
##Libraries Used
- Pandas
- Matplotlib
- Seaborn
##Data Processing
- Converted stock prices in different currencies to INR
- Removed 'Currency' and 'Adj Close' columns
- Updated the csv
- Displayed the maximum and minimum of all numerical columns
##Data Visualisation
- Generated a heatmap depicting Correlation Matrix
- Generated a scatterplot of profit per unit volume of different companies
- Generated a line plot of total profit per month of different companies
##Files
- data_analysis.ipynb - Python analysis code
- Top10VideoGameStocks.csv - Original dataset
- Updated_data.csv - Updated dataset
- PNG files - Generated Visualizations
